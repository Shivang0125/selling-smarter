# Selling Smarter: Rescue Ticket prototype

A working prototype for the Selling Smarter case: catch slow-moving stock at the sales visit, match it to verified unmet demand, and act before the last date to act.

**Live:** https://shivang0125.github.io/selling-smarter/

- **Rep visit:** one nominated stock check and one demand question inside the order flow
- **BDE desk:** tickets sorted by deadline, five gates, distributor tasks, verified outcome
- **Rule checks:** 19 workflow checks that run in the browser on every load

All stores, products and figures are illustrative. Not connected to any company system.
